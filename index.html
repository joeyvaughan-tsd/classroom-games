Classroom Game Hub

Projectable review games you can use with any set of questions. You ask the questions however you like, and the game handles the turns, points and excitement. Click Play to open a game in a new tab, or Directions for step-by-step instructions.

Good to know

Many classes at once

Every game runs separately on each computer, so any number of teachers can play the same game at the same time without affecting each other.

Your settings are remembered

Team names and options are saved in the browser on the computer you use. A teacher who shares a classroom computer will see the last names used and can type over them.

Mistakes are easy to fix

Every game has an Undo button (or U). Buttons that clear scores or end a game need two clicks, so nothing is lost by accident.

Free to use and share

Anyone can open these games: no account or sign-in is needed. Send families the link to this page so they can play at home.
